# Sevrux

A modern hobby operating system written from scratch.

## Features

- x86_64
- Custom cross compiler
- Freestanding kernel
- GRUB bootloader
- C and C++
- Long mode
- Paging
- Memory manager
- Scheduler
- Drivers
- Filesystem

## Toolchain

Target:

```text
x86_64-elf
```

Compiler:

```text
GCC 14.3.0
Binutils 2.45
```

## Build

```bash
make
```

## Run

```bash
make run
```
