## Project Status

Sevrux is currently in its early development stage.

The primary focus is on building a solid and reliable kernel foundation, including the boot process, memory management, interrupt handling, and core system infrastructure.

Higher-level features will be designed and implemented after the base system is stable.

## Planned Features

The feature set is intentionally undecided at this stage.

Once the core architecture is complete, features will be planned based on the project's direction and design goals.
